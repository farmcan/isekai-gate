导出之后，怎么保存和发布？

Live Photo 包：下载 ZIP，解压后在 Mac 打开里面的 livephoto.pvt，导入「照片」。iPhone 直接保存、实况壁纸和小红书原生实况上传仍需设备验证。

发布笔记：可先用导出的视频片段和 JPG 封面；它们是普通视频 / 图片，不会被标成已验证的原生实况图。

建议用桌面版 Chrome 或 Edge 导出。首次导出需加载约 32 MB 转码工具；手机内存不足时可换电脑。原视频声音默认保留。

A LITTLE INSPIRATION

找的是那个瞬间。

先看动作，再挑片段。
不用把整条视频都留下。

01 / 萌宠反应

回头的那一下，刚刚好。

选眼神、歪头或突然定住的 1–3 秒。让封面停在动作之前，长按才有惊喜。

02 / 循环小梗

脑子里已经开始循环了。

选首尾接近、动作清楚的短片段。经典热梗适合试效果，不代表今天的流行榜单。
